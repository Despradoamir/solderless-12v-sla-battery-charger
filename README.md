# solderless-12v-sla-battery-charger
Minimalist, 100% solderless 12V Sealed Lead-Acid (SLA) battery charger locked at 13.9V float voltage. Engineered using EI 57x26 transformer impedance matching, full-length 1N4007 diodes as passive heatsinks, and primary thermal fuse protection—zero PCBs or active regulators required. Designed by Amir Husseinzadeh.
